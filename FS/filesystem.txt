some important functions in file systems nodeJS
1. open('filename.txt','r')
--> used for openieng the file 
2. a.readFile({'encodingformat':utf8});
--> used for reading the content of the file 
3. writeFile(path,data):
--> overwrites a file with new data and createsa file if doesnot exists
4. appendFile(path, data):
--> doesnot overrites but creates a new file if it doesnot exists.
5. rename('old_file_name.txt','new_file_name.txt');
--> renames the old file to a new old_file_name
6. copyFile(srcfile.txt,destfile.txt):
--> copys the content of one file to another file 
--> it overrides the old content and paste the new content of the file.
7.mkdir(path,options)
--> creates a new directory 
--> in options parameter use { recursive:true} for nested structure

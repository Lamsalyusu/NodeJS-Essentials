HTTP -> Hyper Text Transfer Protocol
language that a client and a server use to communicate.
Browser ----> Internet --> Node.js server
Browser sends -> GET /home HTTP/1.1
Server replies -> HTTP/1.1 200 OK <html>..<html>
this is HTTP

HTTP Headers ---> they are key-value metadata pairs sent alongside requests and response in web communication.
they define content types , security policies , caching rules and authentication creds.

Header Parsing ---> node's internal HTTP engine takes the raw , plain-text HTTP protocol stream sent by a client or server and extracts the metadata field into a structured JS object.

Stream Handling ---> treating incoming HTTP requests and outgoing HTTP responses as continuous data flows (streams)
broken into small chunks, rather than processing them as single massive blocks of data in memory. 

example of HTTP message headers:

{ 
  "content-length": "123",
  "content-type": "text/plain",
  "connection": "keep-alive",
  "host": "example.com",
  "accept": "*/*" 
}

======================Creating a Server=========================
1.http.createServer()
---> The most important method
---> It creates a server that listens for requests
---> Client sends request → your server receives it (req)
---> Your server sends back response → client receives it (res)

const http = require('http');
const server = http.createServer((req, res) => {
    // req = what client sent to you
    // res = what you send back to client
    res.write('Hello World');
    res.end();
});

server.listen(3000, () => {
    console.log('Server running at http://localhost:3000');
});

================The Request Object(req)==================
---> when someone hits your server , req contains all infos about that request.
const server = http.createServer((req, res) => {
    
    console.log(req.method);  // GET, POST, PUT, DELETE
    console.log(req.url);     // /users, /products, /login
    console.log(req.headers); // { authorization: 'Bearer token...' }

});

=============Reading Request body (for POST requests)==========
const server = http.createServer((req, res) => {
    let body = '';

    // data comes in chunks
    req.on('data', chunk => {
        body += chunk.toString();
    });

    // when all data received
    req.on('end', () => {
        const parsed = JSON.parse(body);
        console.log(parsed); // { name: 'Yuyutsu', email: 'test@gmail.com' }
    });
});

==============PART 3 - The Response Object(res)====================
res is what you send back to client
res.writeHead(statusCode,headers) --> set status code and headers:
res.writeHead(200,{'Content-Type':'application/json'});
200= OK//content-type tells client what format you are sending.

res.write(data) --> write response body:
res.write('Hello world'); //send text
res.write(JSON.stringify(data)); //send JSON

===================PART 4 HTTP Methods(GET,POST,PUT,DELETE)====================
These are not Node.js methods — they are HTTP protocol methods that the client sends. You handle them in Node.js like this:
const server = http.createServer((req, res) => {

    // GET — client wants to READ data
    if (req.method === 'GET' && req.url === '/users') {
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ users: ['Yuyutsu', 'Ram'] }));
    }

    // POST — client wants to CREATE data
    else if (req.method === 'POST' && req.url === '/users') {
        res.writeHead(201, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ message: 'User created' }));
    }

    // PUT — client wants to UPDATE data
    else if (req.method === 'PUT' && req.url === '/users') {
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ message: 'User updated' }));
    }

    // DELETE — client wants to DELETE data
    else if (req.method === 'DELETE' && req.url === '/users') {
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ message: 'User deleted' }));
    }

    // Route not found
    else {
        res.writeHead(404);
        res.end(JSON.stringify({ error: 'Not found' }));
    }
});

====================PART 5 Making Requests to Other Servers=======================

http.get() - get a make request to another server:

http.get('http://api.example.com/data', (res) => {
    let data = '';
    
    res.on('data', chunk => { data += chunk; });
    res.on('end', () => { console.log(JSON.parse(data)); });
});

=================================================================================

http.request() — make any type of request (GET, POST etc):

const options = {
    hostname: 'api.example.com',
    port: 80,
    path: '/users',
    method: 'POST',
    headers: { 'Content-Type': 'application/json' }
};

const req = http.request(options, (res) => {
    let data = '';
    res.on('data', chunk => { data += chunk; });
    res.on('end', () => { console.log(data); });
});

req.write(JSON.stringify({ name: 'Yuyutsu' }));
req.end();
